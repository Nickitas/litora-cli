# Исследовательские заметки

Здесь хранятся материалы, которые нужны для научного контекста, но не должны
участвовать в сборке и работе CLI.

- `obsidian/` — архив заметок Obsidian вместе с его настройками;
- `administrative/` — административные документы
  регистрации ЭВМ, вынесенные из основного научного контура.
