# AI-01: экспертный набор контрольных фрагментов

## Назначение

`lito seabed expert-set` подготавливает материал для независимой экспертной
оценки адаптивных четырёхугольных сеток. Он не выбирает лучший генератор и не
обучает нейросеть: эти решения остаются за детерминированным отчётом ADAPT-03
и будущей задачей AI-02.

Карточка содержит три слоя в одном фиксированном прямоугольнике LAEA:

1. исходный берег MarineRegions без подмены упрощённой сеточной границей;
2. изобаты принятой модели BATHY-03;
3. все пересекающие окно четырёхугольники одного успешного MSH генератора.

Для одной береговой особенности все варианты используют одинаковые центр,
ширину, высоту, берег и изобаты. SVG не содержит имени генератора, уровня
размера или его места в рейтинге ADAPT-03.

## Запуск

Сначала требуется принятый результат ADAPT-03 и указанные в нём MSH,
батиметрическая модель, паспорт EXPORT-02 и GeoJSON берега:

```bash
./lito seabed expert-set
```

По умолчанию берутся все принятые уровни сравнения. Для компактной пилотной
разметки одного уровня:

```bash
./lito seabed expert-set --levels coarse
```

Стандартный контрольный запуск `coarse` создаёт 16 карточек: восемь окон для
двух успешных генераторов. Packing of Parallelograms не получает пустую
карточку, так как не создал MSH в ADAPT-03; причина включается в закрытый ключ.

Все результаты находятся в `output/seabed/expert-set/`:

| Файл | Получатель | Назначение |
|---|---|---|
| `cards/E-*.svg` | эксперт | анонимные изображения для оценки |
| `expert-rating-template.tsv` | эксперт | общий лист оценивания |
| `training-assignments.tsv` | организатор/эксперт | карточки, допустимые для обучения AI-02 |
| `evaluation-assignments.tsv` | организатор | карточки только для независимой итоговой проверки |
| `participant-instructions.md` | эксперт | единая инструкция и шкала |
| `organizer-key.json` | только организатор | соответствие карточек генераторам, уровням, районам и SHA-256 MSH |
| `expert-set.log` | организатор | журнал создания набора |

`organizer-key.json` нельзя передавать разметчику до завершения оценивания:
он снимает анонимизацию карточек.

## Состав и разделение

В обеих частях есть все четыре класса: коса, залив, остров и изобаты. Район
целиком находится только в одной части, поэтому соседние участки одного берега
не образуют пространственную утечку между обучением и оценкой.

| Часть | Районы и особенности |
|---|---|
| `training` | Тендровская коса, Бургасский залив, остров Змеиный, Крымский шельф |
| `evaluation` | Кызылырмакская коса, Батумский залив, остров Гиресун, Анатолийский склон |

Центры окон хранятся в WGS 84, а размеры — в метрах равноплощадной LAEA. Это
делает набор независимым от пиксельного разрешения SVG и сопоставимым между
запусками.

## Шкала экспертной оценки

Для каждой карточки эксперт вводит оценки 1–5 и комментарий:

| Поле | Значение 1 | Значение 5 |
|---|---|---|
| Берег | особенность плохо передана | форма косы, залива или острова читается уверенно |
| Изобаты | заметны ложные изломы или потеря формы | опорные формы рельефа читаются без ложных изломов |
| Сетка | размер или ориентация ячеек не подходят | сетка адекватно разрешает особенность |
| Артефакты | сильные визуальные или геометрические дефекты | заметных артефактов нет |

Оценивается пригодность сетки для интерпретации, а не красота изображения.
Эксперт не должен пытаться распознать генератор по рисунку.

## Научные ограничения

ADAPT-03 уже подтверждает общую входную границу успешных генераторов. Поэтому
экспертный балл не может быть выдан за новое измерение различия площади берега:
эта величина определяется геометрической метрикой. Карточки добавляют оценку
визуальной читаемости формы и локальной пригодности сетки.

Изобаты берутся из фиксированной BATHY-03, а не являются новыми промерами.
Оценка не превращает GEBCO в навигационный продукт и не заменяет независимые
рейсовые измерения для QA-02.

AI-02 вправе использовать только разметку `training`; `evaluation` остаётся
скрытой до окончательной проверки корреляции и ошибки модели. Даже успешная
ML-модель не заменяет метрики сохранения берега, батиметрии, качества ячеек и
вычислительной устойчивости ADAPT-03.

Машинный ключ имеет схему
[`lito-expert-fragment-set/v1`](schemas/lito-expert-fragment-set-v1.schema.json).
