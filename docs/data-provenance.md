# Происхождение батиметрии и литологии

## Обязательный паспорт батиметрии

Файл `*.json` с точками батиметрии должен сопровождаться одноимённым
`*.metadata.json`. Загрузчик Lito проверяет SHA-256 производного JSON, число
точек и показывает предупреждение, если паспорт отсутствует или имеет статус,
отличный от `verified_derived`.

Паспорт фиксирует:

- продукт и версию источника;
- точный URL и дату загрузки в ISO 8601;
- имя и SHA-256 сохранённого исходного NetCDF;
- исходный и целевой шаг сетки;
- горизонтальную и вертикальную системы отсчёта с оговорками источника;
- границы, метод ресэмплинга, фильтр суши и версии ПО;
- SHA-256 производного JSON;
- лицензию, атрибуцию, условия использования и ограничения.

Исходный NetCDF нельзя удалять после конвертации: одна контрольная сумма без
самого файла позволяет проверить идентичность, но не повторить обработку.

## Статус прежнего файла Чёрного моря

Прежний `data/black-sea-bathymetry.json` не является подтверждённым
ресэмплированным продуктом GEBCO. История Git связывает его появление с
коммитом `49b2edfcdbe2d808ca4eef5dace7967198a41653` от 2026-04-22. Добавленный в
том же коммите генератор выполнял отдельный HTTP-запрос для каждой точки
сетки 0,01°, а при ошибке без отметки подставлял синтетический параболоид.
Ответы сервера, дата получения и признак fallback не сохранялись; NetCDF в
этой процедуре не использовался.

Набор перенесён в
`data/legacy/black-sea-bathymetry-legacy-unverified-0.01deg.json`, снабжён
паспортом со статусом `legacy_unverified_mixed` и больше не подставляется
автоматически. Его SHA-256:
`7b50174d1c66dc73da9fef7b57622c077a86e23bae975aa2b8e2b9092c0da17e`.
Файл оставлен только для аудита старых результатов и технической
совместимости; он не пригоден как эмпирическая батиметрия, для научной
калибровки или навигации.

## Подготовка производного GEBCO

Актуальный на дату этой документации [GEBCO_2026 Grid](https://www.gebco.net/data-products-gridded-bathymetry-data/gebco2026-grid)
и исторический [GEBCO_2024 Grid](https://www.gebco.net/data-products-gridded-bathymetry-data/gebco2024-grid)
имеют шаг 15 угловых секунд. Сетка 0,01° имеет шаг 36 угловых секунд, поэтому
её следует называть только ресэмплированным производным региональным набором,
а не «GEBCO с разрешением 0,01°».

GEBCO хранит высоты в метрах: отрицательные значения соответствуют
батиметрии, положительные — суше. Конвертер Lito не меняет знак и сохраняет
только значения меньше нуля. Он строит целевую регулярную сетку и выбирает
ближайший центр ячейки исходной сетки. Ближайший сосед не повышает фактическую
детальность исходных измерений.

Пример автоматизированной подготовки после получения точного URL выбранной
региональной выгрузки в GEBCO:

```bash
cmd/bathymetry/convert/download_bathymetry.sh \
  'ТОЧНЫЙ_URL_NETCDF_ИЗ_GEBCO' \
  GEBCO_2026 \
  '10.5285/4f68d5c7-45eb-f999-e063-7086abc036fa' \
  output/source/black-sea-bathymetry-gebco2026-0.01deg-derived.json
```

Скрипт сохраняет исходник в `output/source/netcdf/`, производный JSON в
указанном месте и паспорт рядом с ним. Для ручного запуска обязательные
параметры можно посмотреть командой:

```bash
python3 cmd/bathymetry/convert/convert_bathymetry.py --help
```

GEBCO указывает WGS84 как предполагаемую горизонтальную систему отсчёта.
Глобальная модель формируется с допущением среднего уровня моря, однако в
некоторых мелководных районах исходные данные могут относиться к иной
вертикальной системе. Эту оговорку нужно переносить в паспорт, а не заменять
категоричным утверждением о едином datum.

Сетка GEBCO находится в общественном достоянии и допускает копирование,
адаптацию и коммерческое использование. При этом обязательны атрибуция,
запрет на создание впечатления официального одобрения и запрет на искажение
происхождения. GEBCO отдельно запрещает использовать сетку для навигации и
других задач безопасности на море. Точная рекомендуемая атрибуция и отказ от
гарантий приведены на странице выбранной версии продукта.

## Статус литологии

`data/black-sea-lithology.json` имеет статус `alpha_inferred` и не проходил
независимую эмпирическую валидацию. Из 38 точек 11 имеют
`source: "inferred"`; остальные литературные ссылки в текущем файле не
содержат полноценной трассировки до конкретной таблицы, карты, DOI и
геопривязки каждой точки.

Профиль разрешено использовать только как экспериментальную гипотезу для
анализа чувствительности. Его нельзя называть подтверждённой эмпирической
картой, использовать для научной калибровки коэффициентов сопротивления или
подменять им полевые и картографические данные участка. CLI показывает эти
ограничения при каждой загрузке профиля.
