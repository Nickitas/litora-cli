# SVG-визуализация

Команды `lito dimension` и `lito erosion` формируют карты контуров на рабочем поле.

На картах отображаются текущий контур модели, аналитическая сетка, описание
эксперимента, масштаб, стороны света и значения осей OX/OY. Номер итерации или
шага входит в описание эксперимента, а не дублируется в заголовке. OX показывает
долготу в градусах, OY — широту в градусах.

На карте `dimension` оранжевые ячейки — покрытые ячейки `N(ε)`, участвующие в
интерпретации box-counting; оттенок показывает плотность прохождения
дискретизированной береговой линии. На карте `erosion` стрелки показывают
направление волн, а их плотность намеренно уменьшена для читаемости.
Заголовок, описание эксперимента и пояснение сетки выровнены по единой левой
границе научной карты.

Справочная береговая линия, графики, карточки валидации и подробные метрики
остаются в JSON- и табличных результатах, но не перекрывают научную карту.
Координатная сетка отключается в этом режиме, чтобы не смешивать её с сеткой,
которая используется для визуального объяснения box-counting.

## Воспроизводимость

JSON-отчёты содержат блок `reproducibility`: версию схемы метрик, версию
приложения, системы координат, референс проекции и единицы измерения. Параметры seed и модели
сохраняются в соответствующих разделах фрактального и эрозионного отчётов.
Для метрических расчётов используется локальная равнопромежуточная проекция
WGS 84 с референсом в центроиде входной геометрии; её параметры также записаны
в блоке `reproducibility`.
Для box-counting в `dimension.samples` сохраняются все пары масштаба `ε` и
покрытия `N(ε)`, а `dimension.grid_offsets` фиксирует смещения сетки.
Для каждого шага `dimension` также создаётся отдельный `dimension_loglog_*.svg`
с точками всех масштабов и выделенным регрессионным окном.
В JSON сохраняются стандартная ошибка наклона, 95%-й доверительный интервал и
локальные наклоны, позволяющие оценить чувствительность результата к диапазону
масштабов.
Для проверки исходных данных сохраняются SHA-256 входной геометрии и число
точек, а для сетки — её тип, размер ячейки и ширина буферной зоны в километрах.
