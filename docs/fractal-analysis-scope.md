# Границы научной интерпретации фрактального анализа

Lito разделяет анализ наблюдаемой береговой линии и учебную синтетическую
генерацию на две команды.

## `lito dimension`: наблюдаемый контур

Команда передаёт загруженные координаты непосредственно в box-counting-анализ.
Она не вызывает `OrganicKochCurve`, не добавляет точки, не меняет углы сегментов
и не сравнивает результат с `log(4)/log(3)`.

Отчёт содержит оценку `D`, коэффициент `R²`, локальные наклоны, разброс,
доверительный интервал и использованное регрессионное окно. Эти показатели
описывают масштабное поведение конкретного дискретного набора данных. Их следует
интерпретировать вместе с разрешением съёмки, точностью координат, диапазоном
масштабов и устойчивостью регрессии. Число `D` само по себе не доказывает
строгую самоподобную фрактальность природного берега.

В JSON поле `geometry_kind` имеет значение `наблюдаемая`, а
`organic_options` отсутствует. Команда создаёт `dimension_0.svg`,
`dimension_loglog_0.svg` и `dimension.metrics.json` в структуре каталога
`output/`.

Флаг `--full-black-sea` явно выбирает полный наблюдаемый контур MarineRegions
из кэша или официального источника. Квадраты на SVG этой команды остаются
аналитической box-counting-сеткой для оценки `N(ε)` и не являются
пространственными расчётными ячейками Чёрного моря. Последние строятся отдельной
командой `lito mesh` и документированы в
[`mesh-generation.md`](mesh-generation.md).

## `lito koch-demo`: учебный контур

Команда искусственно преобразует базовую полилинию органическим Кох-подобным
генератором. Она предназначена для демонстрации роста числа сегментов и длины,
зависимости измерения от масштаба и проверки реализации box-counting на
синтетической геометрии.

Только в этом режиме показывается справочное значение размерности классической
кривой Коха. Оно не переносится на исходную береговую линию. SVG и JSON явно
маркируются как учебные; в JSON `geometry_kind` равен
`синтетическая-демонстрационная`, а артефакты имеют префикс `koch_demo_`.

## Полный конвейер

`lito all` вызывает тот же наблюдательный анализ, что и `lito dimension`, по
исходным точкам. Последующее упрощение геометрии относится только к численной
эрозионной модели и не меняет вход box-counting-оценки.
