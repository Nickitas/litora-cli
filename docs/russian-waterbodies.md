# Каталог водоёмов Российской Федерации

Команда `lito waterbody list` выводит доступные в Lito моря, озёра и реки
Российской Федерации и сохраняет тот же каталог в
`output/waterbody/catalog.json`. Идентификатор передаётся командам `erosion` и
`all` параметром `--waterbody`.

```bash
./lito waterbody list
./lito all
./lito erosion --waterbody black-sea-sochi --output output/sochi-auto
```

Без аргументов `lito all` и `lito erosion` сами выбирают Сочи — единственный
сейчас водоём с готовым открытым стартовым набором. Он используется из
проверенного кэша; `--refresh` обновляет открытые входы.

## Статусы

- **автоматический стартовый набор** — программа может сама загрузить
  минимальный проверяемый набор данных. Сейчас это участок Сочи на Чёрном море;
- **требуются данные пользователя** — CERC допускается только для локального
  волнового берега, но обязательны `--input`, `--bathymetry` и `--wave-input`;
- **требуется другая модель** — текущая CERC-схема сознательно не запускается.

Для рек действие течения, уровней воды, русловых наносов и устойчивости
откосов определяет береговую динамику сильнее волн. Поэтому Волга, Нева и Дон
зарегистрированы в каталоге, но для них потребуется отдельная русловая модель;
выбирать их для CERC нельзя.

Озёра и моря со статусом «требуются данные пользователя» не получают
вымышленных параметров. Для них CERC можно применять только после проверки
волнового режима, батиметрии и калибровки активного профиля по наблюдениям
конкретного берега.
