# Выбор источника береговой линии

CLI использует строгий порядок выбора источника:

- `--input PATH` читает только указанный локальный JSON/GeoJSON;
- `--source-url URL` включает удалённый режим, когда `--input` не задан;
- если оба флага не заданы, используется локальный файл по умолчанию
  `data/black-sea.json`.

При ошибке чтения `--input` команда завершается с ошибкой. Кэш и удалённый URL
не могут незаметно заменить явно выбранный локальный файл. Аналогично,
удалённый режим не подменяется локальным файлом: при недоступности URL и
отсутствии его кэша возвращается ошибка.

Примеры:

```bash
# Только локальный файл, даже если в кэше есть другой набор данных
./lito dimension --input data/my-coastline.json

# Явно включить удалённый источник
./lito source --source-url https://example.org/coastline.geojson

# Ошибка с ненулевым кодом; fallback на кэш или URL не выполняется
./lito erosion --input data/missing.json
```
