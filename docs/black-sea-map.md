# Обзорная карта побережья Чёрного моря

Команда создаёт самостоятельную географическую карту, которая показывает
границу Чёрного моря и связанное с ней побережье. Это контекстный слой для
исследования, а не расчётная линия одномерной CERC-модели.

```bash
./lito map black-sea
```

При первом запуске Lito получает открытый GeoJSON морского района из
[MarineRegions](https://www.marineregions.org/), сохраняет его в
`data/cache/black-sea.geojson` и затем повторно использует кэш. Чтобы получить
новую версию источника, выполните:

```bash
./lito map black-sea --refresh
```

## Результаты

Команда всегда сохраняет результаты в `output/black-sea-map/`:

- `svg/black-sea-coast.svg` — обзорная карта со слоем стартового участка Сочи;
- `metrics/black-sea-coast.geojson` — два слоя GeoJSON: региональный контур и
  участок Сочи для открытия в ГИС.

Другой каталог можно задать флагом `--output`.

## Границы применимости

MarineRegions публикует геометрию **морского района**, поэтому его граница
годится для обзорной карты всего бассейна, но не заменяет подробную береговую
съёмку, кадастровую границу или проектный топографический план. Lito явно
сохраняет это ограничение в SVG и GeoJSON.

Если нет сети и нет кэша, команда всё же сформирует карту из поставляемой
схематической линии `data/black-sea.json`; в консоли и в SVG появится
предупреждение, что это не полный точный контур. Для CERC такая схема никогда
не используется: модель запускается только на локальном участке с
батиметрией и волновым рядом.
