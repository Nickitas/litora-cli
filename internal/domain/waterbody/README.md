# Каталог водоёмов РФ

Пакет `waterbody` хранит неизменяемый каталог водоёмов и участков водоёмов
Российской Федерации, доступных пользователю Lito. Каждая запись сообщает тип
объекта, применимую физическую схему и статус доступности.

Статус не является заменой исходных данных: он определяет лишь, может ли
текущая версия программы запустить волновую one-line CERC-модель. Реки имеют
статус `требуется другая модель`, поскольку русловую эрозию нельзя корректно
рассчитывать по волновой формуле транспорта наносов.

Публичные функции:

- `List()` возвращает отсортированную копию каталога;
- `Find(id)` ищет объект по стабильному идентификатору для CLI-флага
  `--waterbody`.
