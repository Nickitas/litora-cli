### 2. НАЗНАЧЕНИЕ ПРОГРАММЫ

#### 2.1 Функциональное назначение
Litora-CLI предназначена для:
- Математического моделирования эрозионных процессов прибрежных зон
- Фрактального анализа геометрических свойств береговых линий
- Оценки динамики изменения берега под воздействием природных факторов
- Визуализации результатов моделирования

#### 2.2 Область применения
Программа применяется в следующих областях:
- **Геоморфология и океанология:** научные исследования береговых процессов
- **Экологическое прогнозирование:** оценка рисков эрозии для прибрежных объектов
- **Климатические исследования:** моделирование сценария изменения уровня моря
- **Образование:** обучение методам геоморфологического моделирования
- **Проектирование:** планирование берегозащитных мероприятий

#### 2.3 Круг пользователей
- Научные сотрудники (геоморфологи, океанологи, экологи)
- Преподаватели вузов (географические, геологические факультеты)
- Аспиранты и студенты
- Инженеры-проектировщики берегозащитных сооружений

### 3. ФУНКЦИОНАЛЬНЫЕ ХАРАКТЕРИСТИКИ

#### 3.1 Реализуемые функции

##### 3.1.1 Базовый анализ
| Функция | Описание |
|---------|----------|
| Валидация геометрии | Проверка топологической корректности, замкнутости контуров, пересечений |
| Геодезический расчёт длины | Учёт кривизны Земли через формулу Haversine |
| Метрики качества | Детальная диагностика геометрических проблем |

##### 3.1.2 Фрактальный анализ
| Функция | Описание |
|---------|----------|
| Box-counting размерность | Расчёт фрактальной размерности с усреднением по смещениям сетки |
| Статистическая устойчивость | Адаптивный выбор диапазона масштабов |
| Диагностика сходимости | Анализ изменения размерности по итерациям |

##### 3.1.3 Геоморфологическое моделирование
| Функция | Описание |
|---------|----------|
| Волновая эрозия | Направленность волн, fetch-расстояния, экспозиция берега |
| Батиметрическая интеграция | Загрузка GEBCO данных, билинейная интерполяция |
| Литологический модуль | IDW-интерполяция сопротивления пород |
| Транспорт наносов | Баланс массы, longshore drift, аккумуляция |
| Временная динамика | Штормовые события, сезонность, климатические сценарии (RCP4.5, RCP8.5) |

##### 3.1.4 Визуализация и экспорт
| Функция | Описание |
|---------|----------|
| SVG-отчёты | Визуализация с цветовой кодировкой и метриками |
| GIF-анимация | Анимированная визуализация эрозионных процессов |
| CSV-экспорт | Табличные данные для статистического анализа |
| JSON-экспорт | Структурированные метрики и результаты |

#### 3.2 Математические методы

##### 3.2.1 Геодезические вычисления
- **Гаверсинусное расстояние:** Расстояние между точками на сфере
- **Площадь полигона:** Формула Гаусса (shoelace)

##### 3.2.2 Фрактальный анализ
- **Box-counting метод:** Подсчёт ячеек на различных масштабах
- **Регрессия:** Линейная аппроксимация в логарифмических координатах

##### 3.2.3 Волновая эрозия
- **Модель CERC:** Coastal Engineering Research Center
- **Fetch distance:** Расчёт эффективной длины разгона волны
- **Экспозиция берега:** Угловое распределение волновой энергии

##### 3.2.4 Интерполяция
- **IDW (Inverse Distance Weighting):** Обратная дистанционная весовая интерполяция
- **Билинейная интерполяция:** Оценка глубин в промежуточных точках

#### 3.3 Входные данные
| Тип данных | Формат | Источник |
|-------------|--------|----------|
| Береговая линия | GeoJSON, JSON | Natural Earth, OpenStreetMap |
| Батиметрия | NetCDF (.nc), JSON | GEBCO |
| Литология | JSON | Пользовательские данные |

#### 3.4 Выходные данные
| Тип данных | Формат | Содержание |
|-------------|--------|------------|
| SVG-отчёты | .svg | Визуализация береговой линии с диагностикой |
| GIF-анимация | .gif | Анимированная визуализация эрозии |
| CSV-отчёты | .csv | Метрики по шагам моделирования |
| JSON-метрики | .json | Структурированные результаты |
