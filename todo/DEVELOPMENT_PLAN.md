# План развития Litora-CLI — Научная утилита для геоморфологического моделирования

**Статус проекта:** Базовая функциональность реализована, требуется калибровка и расширение для практического использования.

### 1. Калибровка и верификация модели ⚠️ КРИТИЧНО

**Проблема:** Модель не калибрована на реальных данных. Нет сравнения с измеренной эрозией.

**Задачи:**
- [x] **Контрольные участки (benchmark sites)** — БАЗОВАЯ СТРУКТУРА ГОТОВА
  - [x] Выбор 5 участков Чёрного моря с известными данными эрозии
  - [x] Создание структуры данных для benchmark sites
  - [x] CLI команды: list, init, show, calibrate, extract
  - [x] Хранение в `data/benchmarks/*.json`
  - [x] Подключение детального coastline (9635 точек из GeoJSON)
  - [x] Реальные observation данные (4-6 точек на сайт, основано на публикациях)
  - [x] Создание эталонных dataset'ов для верификации

- [x] **Калибровочные параметры** — АЛГОРИТМ ГОТОВ
  - [x] Grid search по erosion-strength × wave-direction
  - [x] Статистическая валидация (RMSE, MAE, MBE, R², p-value)
  - [x] Per-observation сравнение modelled vs observed
  - [x] Экспорт JSON отчёта
  - [x] Расширенный parameter search (8 strengths × 16 directions = 128 комбинаций)
  - [ ] **TODO:** Реальная высота волн (через wave spectrum)
  - [ ] **TODO:** Расширенный parameter search (lithology factor, depth scale)

- [x] **Статистическая валидация** — ПОЛНАЯ РЕАЛИЗАЦИЯ
  - [x] RMSE, MAE, MBE, R², Pearson r, p-value
  - [x] Анализ чувствительности к параметрам (sensitivity analysis) — OAT анализ
  - [x] Определение доверительных интервалов прогноза (bootstrap) — 200 итераций
  - [x] Сравнение с null model (skill score, improvement %)
  - [x] CLI команда `benchmark analyze` объединяет все метрики

**Пример полного анализа (Kobuleti-ge):**
- Best fit: strength=10 m, direction=22.5°, R²=0.646
- Sensitivity: erosion_strength=0.87 (highly), wave_direction=0.74 (highly)
- Bootstrap 95% CI: strength [5, 15] m, direction [22.5°, 135°]
- Null model comparison: skill score 0.405 (40.5% improvement vs mean)

**Созданные benchmark sites (после инициализации):**
- `odessa-coast-ua` — Odessa Coast, Ukraine — 215 pts, 5 observations
- `kobuleti-ge` — Kobuleti Coast, Georgia — 46 pts, 4 observations
- `balchik-bg` — Balchik Coast, Bulgaria — 136 pts, 5 observations
- `samsun-tr` — Samsun Coast, Turkey — 137 pts, 4 observations
- `anapa-ru` — Anapa Coast, Russia — 59 pts, 6 observations

**Результаты первой калибровки (Kobuleti-ge, текущая модель):**
- Best fit: erosion-strength=10 m, wave-direction=0°
- RMSE: 1.6 m/year, MBE: -1.34 (systematic underestimate)
- R²: -5.2 (модель хуже чем среднее) — **требуется улучшение физики**
- Вывод: упрощённая физика модели не воспроизводит наблюдаемые patterns

**Ключевой вывод:** Реализованный пайплайн калибровки работает, но текущая физическая модель (одно направление волн, без рефракции, упрощённый fetch) недостаточно точна. Следующий приоритет — задача #2 (улучшенная физика).

**Результат:** Калибровочная таблица параметров для различных типов берегов

### 2. Улучшенная физическая модель ⚠️ ВЫСОКИЙ ПРИОРИТЕТ

**Прогресс:**
- [x] Интеграция батиметрии в калибровку — основной рычаг улучшения качества
- [x] Расширенный search space (8 strengths × 16 directions = 128 комбинаций)
- [x] Автозагрузка bathymetry при калибровке
- [x] **Волновой спектр (Gaussian directional spreading)** — Флаг `--spectrum-spread`

**Результаты после интеграции батиметрии + спектра (spread=30):**

| Site | Best Strength | Best WaveDir | RMSE | R² | Improve vs baseline |
|------|---------------|--------------|------|-----|---------------------|
| anapa-ru | 15 m | 292° | 0.70 | **0.23** | +0.02 |
| balchik-bg | 2 m | 68° | 0.38 | -0.26 | -0.04 |
| kobuleti-ge | 15 m | 22° | 0.30 | **0.79** ✓ | +0.14 |
| odessa-coast-ua | 5 m | 225° | 0.81 | -0.34 | -0.03 |
| samsun-tr | 30 m | 338° | 0.37 | **0.85** ✓ | +0.02 |

**Aggregate**: Mean RMSE 0.51 m/year, Mean R² **0.251**, 2/5 statistically significant

```bash

  --name="My Study Site" \
  --country="X" \
  --bounds=44.6,45.5,33.0,36.5 \
  --coast-type=sandy \
  --quality=medium \
  --wave-direction=180 \
  --mean-wave-height=1.2
```
