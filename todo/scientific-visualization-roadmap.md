# План развития научной визуализации и отчёта

Документ описывает последовательное внедрение улучшений для фрактального
анализа и моделирования эрозии. Этапы выполняются по порядку; после каждого
этапа проверяются SVG, JSON-метрики и тесты.

## Принципы

- Расчётная сетка и визуальная сетка должны быть явно различимы.
- На карте остаются только элементы, необходимые для интерпретации результата.
- Все расстояния и размеры ячеек должны иметь метрическую основу.
- Один и тот же масштаб цветов и единицы измерения используются во всех шагах
  одного сценария.
- Каждый результат должен быть воспроизводим по входным данным и параметрам.

## Текущий шаг

Этапы **2. Геодезическая и проекционная корректность** и **3. Полный аудит
box-counting** реализованы. Расчёт
box-counting и обе визуальные сетки используют единую локальную
равнопромежуточную метрическую проекцию WGS 84 с референсом в центроиде входной
геометрии. Параметры проекции сохраняются в JSON.

Следующим выполняется этап **3. Полный аудит box-counting**: сохранение всех
масштабов `ε`, значений `N(ε)`, смещений сетки и параметров регрессии.
Первые два пункта этапа уже сохраняются в поле `dimension.samples` и
`dimension.grid_offsets` JSON-метрик.
График `dimension_loglog_*.svg` показывает регрессионное окно; в JSON также
сохраняются стандартная ошибка, 95%-й доверительный интервал и локальные
наклоны по масштабам.

Следующим выполняется этап **4. Научная карта эрозии**: единая цветовая шкала,
разделение размыва и накопления, а также сопоставимые диапазоны по шагам.
